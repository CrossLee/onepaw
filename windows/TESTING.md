# 一爪 Windows 测试版使用说明

这是 Windows 11 测试版，不是已经完成真机验收的正式版。自动测试、编译成功和生成安装包，不能代替下面的桌面交互验收。x64 与 ARM64 需要分别测试。

## 安装与启动

1. 下载[发布页](https://github.com/CrossLee/onepaw/releases)里的 `一爪-Windows-版本号-Setup.exe`，不需要下载源码或解压其他文件。
2. 双击安装程序，在 Windows 管理员授权提示中确认安装。
3. 在中文向导中点击“安装”，等待安装完成，再点击“完成”。安装器会自动选择 x64 或 ARM64，并安装所需运行库，不需要输入任何命令。
4. 从开始菜单打开“一爪”；也可在完成页勾选立即打开。关闭主窗口后，程序留在通知区域；退出请使用托盘菜单中的“退出”。

安装器包含完整应用，不需要联网下载应用或运行库。安装过程不会导入信任证书、关闭安全功能或永久修改脚本执行策略。开机启动默认关闭，安装后可在一爪设置中开启。

当前仍是未签名预览版，Windows 可能显示未知发布者或安全提醒。只从本项目 GitHub 发布页获取安装文件；如果设备管理策略禁止未签名软件，请联系管理员，不要关闭系统安全设置。本版不用于无人值守批量部署。

请在本人具有管理员权限的 Windows 账户中安装。如果授权时换用了另一管理员账户，安装器会停止并提示，避免把应用安装到错误的账户。

安装新版本会由 Windows 管理应用更新，不先卸载旧版或清空设置。卸载请使用 Windows“设置 → 应用 → 已安装的应用 → 一爪”，不需要运行命令。

一爪沿用旧版的包身份和数据目录。任务管理器中的内部进程文件名 `Crosio.exe`、旧数据路径和系统注册标识可能仍包含 `Crosio`，这是保留升级兼容，不代表安装了两款应用。历史预览版安装包也保留原来的文件名。

## 建议先验收这几个操作

- 更名与升级：检查开始菜单、主窗口、通知区域、安装向导、系统应用列表和图片打开方式均显示“一爪”；从旧版升级后，已有设置、翻译模型和文件仍可用，没有重复的应用条目。代码中的兼容标识检查不能替代实际升级验收。
- 区域截图：按 `Ctrl+Shift+1`，选一个小区域，立刻到其他程序粘贴，确认已有图片。关闭截图编辑器只需一次 `Esc`，主界面不应被重新打开。
- 截图贴图：截图编辑器按 `S`，确认只有所选小图置顶；滚轮缩放，`Esc` 关闭。
- 右键复制路径：分别测试中文文件名、文件夹、多选文件；路径应正确，主界面不应弹出。此项必须安装 MSIX，直接运行解压目录不会注册资源管理器菜单。
- 图片打开方式：选择“打开方式 → 一爪”，应自动压缩并在资源管理器定位结果；原文件不能被覆盖，输出后缀和真实编码要保持一致。
- 自动 OCR：截取含中文和英文的区域，检查识别文本。此功能在本机运行，不上传截图。
- 文本翻译：先在设置中设置翻译快捷键，并在翻译页安装中英双向模型。选中中文或英文后按快捷键，应自动填入并翻译为另一种语言。首次下载模型需要联网；模型安装后的推理不联网。
- 录屏：分别录制屏幕、区域、窗口，停止后播放 MP4，检查画面、系统声音和鼠标。Windows N/KN 需先启用系统的 Media Feature Pack。
- 长截图：测试浏览器长页面的上下衔接、固定页头和到达底部；不要只检查是否生成了图片文件。
- 共享：先确认默认访问码为 10 位；分别从共享页和“设置 → 共享服务”改成 6–24 位自定义访问码，确认旧链接立即失效、新链接保留原端口与共享内容，自定义码重启后仍保留；再恢复随机访问码。用另一台设备测试文件下载、文件上传和文字发送；按“停止共享”后旧链接必须失效。
- 开机启动：在一爪设置启用后注销并重新登录；应只驻留通知区域，不弹主窗口。关闭该设置后再次登录确认不会启动。
