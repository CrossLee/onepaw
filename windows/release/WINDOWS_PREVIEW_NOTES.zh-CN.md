# 一爪 Windows 11 预览版

现在提供普通用户可直接双击的 **Windows 11 中文图形安装程序**，自动选择 x64 或 ARM64，不需要使用 PowerShell、输入命令或另外安装运行库。

下载下面的 `一爪-Windows-…-Setup.exe`，双击 → 确认 Windows 管理员授权 → 点击“安装” → “完成”。之后从开始菜单打开“一爪”，也可以在完成页勾选立即打开。卸载入口在 Windows“设置 → 应用 → 已安装的应用 → 一爪”。

安装包内已包含完整应用，安装无需联网；翻译模型首次下载另需联网。发布页的 `SHA256SUMS.txt` 是安装程序的校验值，普通用户无需下载它才能安装。

本版仍是**未签名预览版**，Windows 可能显示未知发布者或安全提示；安装器不会导入信任证书、关闭安全功能或永久修改脚本执行策略。它不是正式受信任的生产发行版，也不代表所有功能已经与 macOS 完成一致性验收。如果设备策略禁止未签名程序，请联系管理员，不要关闭安全设置。

当前测试版需使用本人具有管理员权限的 Windows 账户安装；如果授权时换用了另一管理员账户，安装器会停止并提示，避免安装到错误账户。

## 本次更新：共享访问码可自定义

- 局域网文件、文字和上传共享默认改用 10 位易读随机访问码。
- 可在共享页或“设置 → 共享服务”保存 6–24 位自定义访问码，支持英文字母、数字、`-` 和 `_`，并区分大小写。
- 在线换码不会改变端口或清空共享内容；旧链接立即失效，新链接继续使用当前共享内容。
- 访问码会明文出现在共享链接和浏览器历史中，仅用于减少误访问，不等同于账号密码或端到端加密，请勿复用重要密码。

## 品牌更新：统一为“一爪”

产品的用户可见名称统一为“一爪”，覆盖开始菜单、应用与截图工具窗口、通知区域、共享网页、图片文件关联和中文安装器；新安装包文件名使用 `一爪-Windows-版本号-Setup.exe`。电脑小事，一爪搞定。

继续使用已确认的“一爪 OnePaw”猫咪伸爪图标，不重新设计或修改图稿。包身份、Publisher、协议、COM 注册、内部 `Crosio.exe` 文件名和已有数据目录保持兼容；更名不以卸载旧版或清空设置为前提。历史版本标签、下载文件名和验收记录不改写。
